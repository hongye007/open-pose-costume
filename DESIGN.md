# Design principles

For illustrators and character designers: browse poses and outfits, inspect details, and pair useful references.

Palette: background #f4f6f8, paper #ffffff, text #232a37, secondary text #737c8e, accent #3d5bd9, lavender #eceafa. Georgia and Songti SC for display text, system fonts for body text, monospace for IDs.

Desktop uses a sidebar and responsive reference grid. Mobile moves navigation above a two-column grid. Large images, angle thumbnails and the pairing board support close comparison.

Keep the introduction compact and the references prominent. Show actual counts and source IDs. Prioritize readable controls, keyboard access and useful image space.
