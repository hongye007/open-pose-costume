# 素材分类与筛选结构

## 数据现状

本地索引共有 3,277 组参考：302 组姿势、1,448 套服饰、1,527 张人物参考。左侧导航与筛选结果只统计当前内容范围允许显示的素材；“显示扩展分类”仍控制双人、曲线、内衣泳装等扩展内容。数字以实际构建的数据为准。

| 层级       | 用途                 | 当前维度                                                   |
| ---------- | -------------------- | ---------------------------------------------------------- |
| 素材类型   | 确定找什么           | 通过侧栏切换姿势、服饰、人物；收藏页可进一步缩小类型       |
| 分类       | 类型内部的主要目录   | 姿势按动作；服饰按季节、场合；人物按人脸、人物造型         |
| 素材库     | 素材所在集合         | 全部、基础素材、自建扩展                                   |
| 人物标签   | 已明确标注的人物属性 | 女性、男性；未标注素材不推定性别                           |
| 画面风格   | 已明确标注的表现方式 | 结构线稿、写实、动漫                                       |
| 国家／地区 | 人物参考的编辑分组   | 日本、法国等 11 国；未指定国家的新增人物为“国际（未细分）” |
| 人物发长   | 人物参考专用属性     | 短发、中发、中长发、长发                                   |
| 搜索       | 全文缩小范围         | 中英文标题、关键词、内部 ID、分类、系列、标签              |

类别保留已有数据，不把动作与季节混成同一平铺列表。分类下拉在全部/收藏页按姿势、服饰、人物分组。人物标签与画面风格分别单选，不同维度取交集，例如“男性 + 写实 + 人脸”。

根据维护者确认，原有的 288 组姿势、1,438 套服饰（含 31 套此前的自建服饰）和 1,499 张人物参考统一标注为“女性”，其中 1,407 套基础服饰和原有人物参考另标注“写实”。新增男性素材保留各自的性别及风格标签。基础素材标注在数据构建阶段补充，自建素材在清单中记录，重新同步后仍保留，不修改上游原始快照。标签筛选数量只代表已标注的素材，后续未标注素材不自动继承这些属性。新增 22 张多地区人物参考按生成档案记录男女及发长，支持中英文国家名称搜索；原有 1,499 张人物按维护者确认归入日本组；22 张新增多地区人物按生成档案归入对应国家，6 张未指定国家的男性人物归入“国际（未细分）”。人物使用独立的 `country: { id, zh, en }` 字段，卡片显示国家标签，图库和选图弹窗可按国家／地区与性别、风格、发长交叉筛选，并支持国家名称中英文搜索。国家名称仅为编辑分组，不推定真实国籍。瞳色、发色、肤色目前记录在本批次关键词中，尚未结构化，不根据图片或名称自动补标。

## 交互规则

- 选项数量随搜索及其他条件更新，分类数量在忽略当前分类后计算，方便更换分类。零结果选项不可新选；已选条件保留以便取消。
- 筛选下拉共用紧凑的弹出菜单，分类按素材类型分组，数量右对齐；支持方向键、Home/End、Enter、Esc 与点击外部关闭，在窄屏和选图弹窗内使用浏览器顶层显示，避免被滚动容器裁切。
- 已选条件显示在筛选区下方，每项可单独移除，也可清除全部筛选。
- 全部参考不再提供素材类型筛选，使用侧栏或按类型分组的分类菜单定位；收藏页切换素材类型会清除分类与发长，保留搜索、素材库、人物及风格条件。
- 切换左侧图库类型会重置筛选，避免跨类型携带无效分类。
- 排序、展示视角与深度图属于展示设置，不是筛选条件。“清除筛选”保留这些展示选择。
- 深度图及视角只在当前结果含姿势时出现；已完成配套深度图的男性姿势切换到本地灰度版本；没有配套深度图的自建姿势仍展示原线稿并明确提示，当前结果全部不支持深度图时不能开启，但可以关闭已开启状态。工作台也显示所选姿势的深度图可用性。
- 排序支持默认顺序/多类型交替浏览、按中英名称、按可见编号（数字自然排序）。当前没有可靠创建时间，不提供“最新”排序。
- 筛选、排序和全局视角写入 URL（国家／地区使用 `country=jp/fr/international` 等）；旧链接的 `tag=anime/photo/line-art` 自动迁移到独立风格条件，`tag=male/female` 保留人物标签。
- 生图选图器复用同一分类、素材库、人物标签及风格交集逻辑，顶部筛选区域继续常驻。

## 后续数据扩展

若继续扩充素材，应先补齐数据契约：人物属性与表现风格分开记录；“未知”保留为未知；服饰可把季节、场合和服装品类逐步拆为独立维度；姿势可补人数、取景范围和道具等属性。批量补标需逐图核对，再启用对应筛选，不从零散关键词直接推断。
