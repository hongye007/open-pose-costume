## 查找与收藏

- **三类参考，一处查找**：浏览姿势、服饰与人物，按中英文名称、关键词或编号搜索，配合分类、素材库、人物标签、画面风格，以及人物专用的国家／地区与发长筛选定位素材。排序与展示视角独立于筛选；全部参考页通过侧栏或分组分类菜单定位素材类型。
- **多视角与深度图**：切换姿势视角，按需查看深度图；卡片悬停或点击小图只切换当前卡片。列表加载缩略图，详情可放大查看并下载原图。已有配套深度图的自建姿势也支持切换，没有深度图时保留线稿并提示。扩展分类可单独开启。
- **收藏与分享**：收藏喜欢的素材，随时从“我的收藏”继续搭配或下载；分享链接保留语言、筛选与参考选择。
- **连续浏览**：响应式布局、图片懒加载，向下滚动自动加载更多；支持 `/` 搜索、详情中 `←` / `→` 切换、`Esc` 关闭。

人物库共 **1,527 张参考**：原有 893 张人脸、606 张人物造型图，以及 28 张自建头肩人像。原始姿势、写实服饰与人物已按维护者确认标注为女性，写实服饰与人物同时标注为“写实”；新增动漫服饰标注为“女性／动漫”，男性素材保留“男性”标签。人物支持国家／地区和发长筛选；瞳色、发色、肤色尚无完整的独立结构化筛选，部分自建人物可按描述关键词搜索。

## 姿势、服饰与人物，一键生成

从侧边栏进入“一键生图”，左侧挑选参考、设置生成参数，右侧查看结果。**姿势和服饰必选，人物参考可选**：姿势决定动作，服饰决定穿搭，人物参考用于保留身份与外貌。可从素材库挑选，也可点击“随机搭配”寻找灵感。

![中文一键生图工作台：姿势、服饰与可选人物参考，风格、尺寸设置及生成结果](docs/images/generation-studio-v2-zh.webp)

### 从参考到成图

1. **配置服务**：点击“配置生图服务”或右上角设置，填写服务地址、API Key 与模型；未配置 API 时生成按钮不可用。
2. **选择参考**：选好姿势和服饰，按需从人物库选择或上传人物参考。支持上传、拖拽或粘贴 PNG、JPG、WebP，单张最大 10 MB。
3. **提取自有服饰**：点击“上传服饰”直接打开弹窗，在左侧选择穿搭图片，点击中间的“提取服饰”，检查右侧结果后点击“确认使用”。提取会额外发起一次生图请求，失败可重试，确认前不替换原参考。
4. **调整并生成**：在姿势选择弹窗中点击小缩略图切换单张卡片视角，再点击大图选用；选择观察角度、按需启用深度参考，设置画面风格（跟随参考、自然写真、影棚质感或动漫插画）、尺寸与补充描述；高级设置支持编辑完整提示词。点击“生成图片”后可继续浏览图库，失败可手动重试。
5. **查看与继续创作**：在“仅结果”“双列预览”“叠加预览”中切换，放大或下载结果，也可点击“用此人物继续生成”。“历史记录”右侧抽屉保留最近 20 次成功结果，支持恢复搭配、删除记录，以及打包下载该次使用的姿势、服饰和人物参考图（如有）。

| 配置项     | 默认值或要求                                                                            |
| ---------- | --------------------------------------------------------------------------------------- |
| 服务地址   | `https://atomflow.vip`，可修改                                                          |
| 模型       | `gpt-image-2`，可修改                                                                   |
| 接口       | `POST /v1/images/edits`，OpenAI 兼容 multipart 格式                                     |
| 参考图     | 通过 `image[]` 上传姿势、服饰两张原图；选传人物图时共三张                               |
| 浏览器访问 | 静态部署需服务允许携带 `Authorization` 的 CORS 请求；本地 Atomflow 开发请求通过同源转发 |

<summary>密钥、图片与历史记录如何保存？</summary>

配置保存在当前浏览器，API Key 默认仅保存到当前会话；勾选“记住密钥”后存入本地存储，可在设置中清除。生成时，参考图和描述会发送至配置的服务，费用以该服务为准；本地开发中的 Atomflow 请求经 Vite 同源转发，静态部署直接请求该服务。密钥不会进入分享链接或仓库。

库中参考选择以素材编号保存在当前浏览器；列表使用缩略图；自建素材详情使用 WebP 预览，生成与原图下载使用高清 PNG；原有素材按索引加载对应预览与原图。上传服饰时，原始穿搭图会在点击“提取服饰”后发送至所配置的服务；确认后的提取结果作为服饰参考参与后续生成。

## 配套 Skill

[open-pose-costume-skill](https://github.com/hongye007/open-pose-costume-skill) 将姿势、服饰与人物参考组合生成为一张人物图，让你在 Codex 中通过自然语言使用这套创作流程。网站用于浏览和挑选参考，Skill 用于执行人物生成；安装方法、示例与生图服务配置见 Skill 仓库的中英文 README。

## 本地运行

需要 **Node.js 22.12+**。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5199>。项目启用严格端口检查，占用时会退出；启动前请检查端口，或选择其他空闲端口：

```sh
npm run dev -- --port 5200
```

可用 `lsof -nP -iTCP:5200 -sTCP:LISTEN`（macOS/Linux）或 `Get-NetTCPConnection -LocalPort 5200`（Windows PowerShell）检查占用。

本地 `npm run dev` 会将 Atomflow 的 `/v1/images/edits` 请求通过 Vite 同源转发到配置的 `atomflow.vip` 或 `api.atomflow.vip`，避免浏览器跨域限制；密钥仅随当前请求转发。其他服务地址、构建后的静态网站和 `npm run preview` 仍直接请求生图服务，需要服务允许 `Authorization` 请求头的 CORS 访问。

## 构建与部署

当前使用 [GitHub Pages](https://hongye007.github.io/open-pose-costume/) 部署。推送到 `main` 后，GitHub Actions 自动运行测试、以 `/open-pose-costume/` 为基础路径构建并部署；测试或构建失败时不会更新网站。其他分支及拉取请求只执行检查。

CI 使用稀疏检出，跳过根目录 `pose/`、`costume/` 上游图片归档的下载与检出。`public/custom/` 下的自建图片参与检出和构建，随网站部署。

基于 **React 19 · TypeScript · Vite · Lucide**。参考库是静态网站，参考生成需自行配置生图服务。

```sh
npm run build
```

将 `dist/` 部署到静态托管平台即可。Cloudflare Pages 设置构建命令为 `npm run build`、输出目录为 `dist`。`public/_headers` 在 Cloudflare Pages 上提供缓存与安全响应头，GitHub Pages 不读取此文件。

本地预览同样选择空闲端口：

```sh
npm run preview -- --port 5200
```

## 数据与维护

动漫服饰元数据独立保存在 `data/source/costume-anime.json`，与原写实服饰快照分别维护，重建时合并到统一索引。`npm run sync -- --costume-anime-only` 可单独更新该来源，保留其他快照与自建清单；上游动漫图片不纳入批量归档命令。

原有素材继续使用原站图片链接，可用性取决于上游站点；根目录的本地图片归档不改变这些地址。自建素材从 `public/custom/` 随网站构建发布，使用本站图片地址。

人物库元数据来自 [AI Portrait Gallery](https://ai-portrait-gallery.pages.dev/)，人物原图与缩略图未下载或纳入仓库，也不包含在 `images:download` 命令中。

| 命令                      | 用途                                                               |
| ------------------------- | ------------------------------------------------------------------ |
| `npm run sync`            | 同步上游元数据，不执行上游网页代码或下载图片                       |
| `npm run data:build`      | 从上游本地快照与自建清单重建网站索引                               |
| `npm test`                | 运行测试                                                           |
| `npm run build`           | 类型检查并构建网站                                                 |
| `npm run images:download` | 可选：归档上游姿势、服饰的封面与原图；不含人物、上游动漫和自建素材 |

元数据快照位于 `data/source/`，网站索引位于 `public/data/catalog.json`，同步记录位于 `data/sync-manifest.json`。同步会检查分类、视角及翻译完整性；如缺少翻译，按报错补充词表。

自建扩展独立维护在 [`data/custom/`](data/custom/README.md)，与 `data/source/` 上游快照分开；服饰、姿势、人像分别使用 `costume.json`、`pose.json`、`character.json` 清单。图片存放在 `public/custom/{costume,pose,character}/{originals,images,thumbnails}/`。重建索引与上游同步都会合并自建条目并重算数量，不会覆盖自建清单。扩充步骤与批次记录见 [自建扩展说明](data/custom/README.md)。
