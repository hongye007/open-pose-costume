使用指引

从选取姿势、服饰和人物，到配置生图服务与排查请求错误。

打开一键生图

选择参考素材

  1. 在图库按类别、关键词或编号查找姿势、服饰和人物。点开卡片可查看原图。
  2. 将姿势和服饰加入搭配台，按需选一张人物图。若姿势有多视角和配套深度图，可切换观察角度或开启「深度图」。
  3. 进入「一键生图」，确认素材、模型和尺寸，按需补充描述，再生成图片。

配置生图 API

  1. 打开「一键生图」，点击「生图设置」。
  2. 如果使用 Atomflow，在其控制台的「API 密钥」中新建密钥。参考资料使用 codex 分组和 gpt-image-2 模型，实际可用模型和额度以账户控制台为准。
  3. 将 API 地址、密钥和模型填入生图设置并保存。需要下次继续使用时，可选择在当前浏览器中保存密钥。
  4. 使用其他服务时，填写该服务的 API 地址和模型，并确认它支持 /v1/images/edits 图片编辑接口和多张参考图。

打开 Atomflow 控制台入口

排查生成错误

HTTP 400 · 请求参数或参考图被拒绝

先查看服务返回的错误详情，核对模型、尺寸和支持的图像格式。上传图片使用 PNG、JPEG 或 WebP。若同一组素材反复失败，可逐个更换参考图或简化提示词，定位触发错误的输入。

HTTP 403 · 服务拒绝访问

到服务控制台核对密钥状态、模型权限、分组和余额。若错误明确提示额度不足，再按服务商的说明处理。

记录错误详情、所用服务地址和模型有助于定位问题。分享截图或日志前请遮住 API 密钥。
